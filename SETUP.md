# Первая настройка на компьютере (Windows)

Этот файл — инструкция для Claude Code, запущенного на компьютере Дины в этой папке.
Написан в облачной сессии на Linux: команды для Windows здесь не запускались и не
проверены. Проверять каждый шаг по факту и исправлять этот файл, если что-то не так.

Дине достаточно написать: «Прочитай SETUP.md и настрой всё по шагам».

## Шаг 1. Проверить, что уже установлено

```powershell
ffmpeg -version
node --version
python --version
git --version
```

## Шаг 2. Установить недостающее

Через winget (встроен в Windows 10/11). Каждую установку объяснить Дине одной
фразой и дождаться её согласия.

```powershell
winget install Gyan.FFmpeg
winget install OpenJS.NodeJS.LTS
winget install Python.Python.3.12
winget install Git.Git
```

После установки открыть новое окно терминала и повторить шаг 1.

Что для чего:

| Инструмент | Зачем |
|---|---|
| ffmpeg | резка, склейка, цвет, звук, сборка mp4 |
| Node.js | сборка анимированных субтитров и вставок (Remotion) |
| Python | распознавание речи и вырезание человека из фона |
| Git | сохранять скиллы и шаблоны в репозиторий |

## Шаг 3. Распознавание речи

Нужны таймкоды по каждому слову, язык русский. Вариант по умолчанию —
`faster-whisper` (работает на компьютере, бесплатно, видео никуда не отправляется).

```powershell
python -m venv .venv
.venv\Scripts\pip install faster-whisper
```

Проверить на коротком куске реального ролика Дины. Если на её компьютере слишком
медленно или много ошибок — предложить Дине платный онлайн-сервис распознавания и
объяснить разницу; без её согласия видео в сторонние сервисы не отправлять.

## Шаг 4. Вырезание человека из фона

Нужно для текста и вставок за спиной. Проверить на реальном ролике 2 варианта и
выбрать тот, где чище край волос и нет мерцания: `rembg` (покадрово) или
MediaPipe Selfie Segmentation. Сравнение показать Дине картинками.

## Шаг 5. Папки

Уже есть в репозитории: `projects/`, `templates/`, `music/`, `references/`.
Для каждого нового ролика создавать `projects/<название>/` со структурой из скилла.

## Шаг 6. Референсы

Попросить Дину положить в `references/` три ролика-примера файлами (ссылки —
в `references/links.md`). Разобрать: шрифты, размеры и цвета субтитров, как часто и
насколько сильно наезды, ч/б фрагменты, вставки за спиной. Записать разбор в
`references/razbor.md` и сделать первые шаблоны в `templates/`.

Разбор — для того, чтобы перенять приёмы оформления. Чужие кадры, тексты и музыку
в ролики Дины не брать.

## Шаг 7. Вопросы к Дине

Пройти раздел «Уточнить» в `.claude/skills/reels-dina-padini/SKILL.md`, ответы
сразу вписать в скилл.

## Шаг 8. Пробный ролик

Собрать один короткий ролик Дины целиком: чистка речи → субтитры → наезды → цвет →
музыка. По итогам поправить скилл и убрать из него пометку «ЧЕРНОВИК».

## Что стоит денег

Всё перечисленное выше бесплатно. Платными будут только сервисы, если Дина их
захочет: синтез голоса, генерация картинок, онлайн-распознавание речи. Подключать
только по её просьбе; ключи не записывать в файлы репозитория.
