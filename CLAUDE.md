# Video-

Рабочая папка Дины для монтажа роликов с помощью Claude Code.

## О пользователе

- Дина — блогер, не программист. Говорить по-русски, простыми словами, без кода и
  терминов. Результат показывать картинкой или видео.
- Компьютер — Windows. Все команды и инструкции — для Windows.
- Часто диктует голосом, в тексте бывают ошибки распознавания («глотка», «клод» =
  Claude). Понимать по смыслу.

## Проекты

- **DINA PADINI** — рилсы для Instagram. Скилл `reels-dina-padini`.
- **Детские ролики** — отдельный проект с отдельным скиллом. Скилла ещё нет; когда
  Дина попросит, расспросить и создать рядом, не смешивая с DINA PADINI.

## Правила

- Исходные видео не изменять и не удалять.
- Видео, музыку и картинки в git не добавлять — они исключены в `.gitignore`.
  В git хранятся только скиллы, шаблоны и текстовые файлы.
- Пока инструменты не установлены и первый ролик не собран, раздел «Уточнить»
  в скилле — это список вопросов к Дине, а не решённые вещи.
- Если по ходу работы Дина меняет или уточняет правила оформления — сразу вносить
  это в скилл, чтобы не объяснять второй раз.

## Первая настройка

Описана в `SETUP.md`. Выполняется один раз на компьютере Дины.
