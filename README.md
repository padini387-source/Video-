# Video-

Монтаж роликов с помощью Claude Code.

## Что здесь

| Что | Где |
|---|---|
| Скилл монтажа рилсов DINA PADINI (черновик) | `.claude/skills/reels-dina-padini/` |
| Общие правила для Claude | `CLAUDE.md` |
| Настройка компьютера, шаг за шагом | `SETUP.md` |
| Ссылки на ролики-примеры | `references/links.md` |
| Ролики в работе | `projects/` |
| Шаблоны оформления и цвета | `templates/` |
| Фоновая музыка | `music/` |

Скилл для детских роликов — будет отдельным, пока не создан.

## Как начать на компьютере

1. Установить приложение Claude для Windows и войти в свой аккаунт.
2. Скачать этот репозиторий в папку на компьютере и открыть её в Claude Code.
3. Написать: «Прочитай SETUP.md и настрой всё по шагам».

## Как потом работать

Положить видео в `projects/<название-ролика>/source/` и написать, например:

- «Смонтируй рилс из папки kafe, говорящая голова, субтитры акцентные»
- «Просто озвучка и субтитры, собери ролик по моим видео из папки kafe»
- «На 12-й секунде добавь самолёт», «убери картинку на 0:08»
- «Во фразе про кофе возьми второй дубль»

Исходные видео, музыка и картинки в git не попадают — они остаются только на
компьютере.
