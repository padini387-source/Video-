# Video-

Монтаж роликов с помощью Claude Code.

## Что здесь

- `.claude/skills/reels-dina-padini/` — скилл для монтажа рилсов проекта DINA PADINI
  (черновик, записан с телефона).
- Скилл для детских роликов — будет отдельным, пока не создан.

## Первый запуск на компьютере

1. Открыть этот репозиторий в Claude Code (десктоп-приложение) в своей рабочей папке.
2. Написать: «Прочитай README и скилл reels-dina-padini, пройдись по разделу
   "Уточнить" и настрой всё для монтажа».
3. Claude должен: задать вопросы из раздела «Уточнить», установить инструменты
   (ffmpeg, Node, распознавание речи, вырезание человека из фона), создать папки
   `projects/`, `templates/`, `references/`, разобрать ролики-примеры и собрать
   первый шаблон.

Исходные видео в git не хранить — они большие. Папки `source/` и `out/` исключены
в `.gitignore`.
